## Política estricta de recortes

- Queda **prohibido** adjuntar capturas de pantalla completa (escritorio, barra de tareas del SO, pestañas del navegador o espacio sobrante).
- Toda evidencia debe **recortarse exclusivamente al contenedor/panel** del elemento de Jira a demostrar.
- Las capturas que incumplan esta norma restarán el **50 %** del puntaje asignado a la sección.
- Formato recomendado: PNG, ancho máximo 1200 px.
