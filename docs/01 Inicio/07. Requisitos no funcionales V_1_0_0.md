# Requisitos No Funcionales (RNF)

Proyecto: PathSeek
Código del documento: DOC-007
Versión: V_1_0_0
Fecha: 2026-08-25

---

## 1. Marco de Calidad

Los requisitos no funcionales se definen mediante **Escenarios de Calidad** siguiendo el modelo ISO/IEC 25010 y las prácticas de arc42. Cada requisito especifica una escala completa (Fuente → Estímulo → Entorno → Artefacto → Respuesta → Medida SLA) y métricas SMART.

---

## 2. Catálogo de Requisitos No Funcionales

### RNF-001: Rendimiento del Algoritmo de Optimización

| Campo | Descripción |
| ----- | ----------- |
| **ID** | RNF-001 |
| **Categoría ISO 25010** | Eficiencia de rendimiento |
| **Fuente** | Usuario concurrente (operador/logístico) |
| **Estímulo** | Solicitud de generación de rutas optimizadas |
| **Entorno** | Operación normal con carga máxima (80% capacidad) |
| **Artefacto** | Módulo de Optimización (metaheurística) |
| **Respuesta** | Procesar la solicitud y retornar las rutas óptimas |
| **Medida SLA** | Latencia ≤ 45 segundos en el percentil 95 (P95) para 150 pedidos y 15 vehículos |

---

### RNF-002: Rendimiento de Re-optimización

| Campo | Descripción |
| ----- | ----------- |
| **ID** | RNF-002 |
| **Categoría ISO 25010** | Eficiencia de rendimiento |
| **Fuente** | Sistema de monitoreo de tráfico / operador |
| **Estímulo** | Evento de cambio (nuevo pedido, cancelación, accidente, avería) |
| **Entorno** | Operación en horario punta (7:00-9:00 AM, 5:00-8:00 PM) |
| **Artefacto** | Módulo de Re-optimización Dinámica |
| **Respuesta** | Recalcular rutas afectadas y notificar a conductores |
| **Medida SLA** | Tiempo de re-optimización ≤ 30 segundos ante cambios repentinos |

---

### RNF-003: Seguridad

| Campo | Descripción |
| ----- | ----------- |
| **ID** | RNF-003 |
| **Categoría ISO 25010** | Seguridad |
| **Fuente** | Atacante externo / usuario no autorizado |
| **Estímulo** | Intento de inyección SQL, XSS, CSRF o acceso no autorizado |
| **Entorno** | Producción |
| **Artefacto** | API Gateway / WAF / Capa de autenticación |
| **Respuesta** | Bloquear petición, registrar evento de auditoría y notificar |
| **Medida SLA** | 0% de vulnerabilidades críticas OWASP Top 10 ejecutables; cumplimiento Ley N.° 29733 |

---

### RNF-004: Disponibilidad

| Campo | Descripción |
| ----- | ----------- |
| **ID** | RNF-004 |
| **Categoría ISO 25010** | Fiabilidad |
| **Fuente** | Usuarios del sistema en horario operativo |
| **Estímulo** | Solicitud de acceso al sistema |
| **Entorno** | Operación de 5:00 AM a 10:00 PM, lunes a sábado |
| **Artefacto** | Plataforma web completa (frontend + backend + BD) |
| **Respuesta** | Servir la solicitud correctamente |
| **Medida SLA** | Disponibilidad ≥ 99.5% anual en horario operativo; RTO ≤ 30 segundos, RPO ≤ 5 segundos |

---

### RNF-005: Escalabilidad

| Campo | Descripción |
| ----- | ----------- |
| **ID** | RNF-005 |
| **Categoría ISO 25010** | Portabilidad / Adaptabilidad |
| **Fuente** | Crecimiento del volumen de operaciones |
| **Estímulo** | Incremento proyectado de pedidos y vehículos |
| **Entorno** | Expansión a nuevos distritos (Los Olivos, Comas, Independencia) |
| **Artefacto** | Arquitectura del sistema (backend + BD) |
| **Respuesta** | Mantener rendimiento sin degradación |
| **Medida SLA** | Soporte para hasta 1,000 pedidos diarios y 50 vehículos sin degradación del SLA de rendimiento |

| **Respuesta** | Consultar ruta, entregas pendientes y alertas de tráfico |
| **Medida SLA** | Interfaz comprensible sin capacitación; satisfacción ≥ 4.0/5.0 |

| Campo | Descripción |
| ----- | ----------- |
| **ID** | RNF-008 |

| **Estímulo** | Conexión de baja velocidad (2G/3G) o intermitente |

| **Respuesta** | Cargar interfaz y datos esenciales de la ruta |
